Where Mnemolith is heading.

Today Mnemolith gives AI coding tools a shared memory that knows when it’s out of date. Next, that memory becomes something a whole team shares and reviews. Then it reaches people who don’t write code. Last updated November 5, 2026.

Today

Version 0.3.4. One memory shared by Claude Code, Claude Desktop, Cursor and Codex, tied to the files each fact depends on and flagged when those files change. Mender drafts the fix for a stale memory and you approve it, and a local dashboard shows what your AI knows and why.

It helps: on tasks that need knowledge the code doesn’t show, Claude got 43% right with no memory and 100% with Mnemolith. See the evaluation.

Next: team memory

December to February. Each person keeps their own memories, and each repo gets one shared team memory that every teammate’s AI reads, so nobody’s AI rediscovers what the team already knows. You promote a memory to the team on purpose, with a clear heads-up that everyone with access to the repo will see it.

Team memories live in the repo as plain files. Mnemolith writes the file; you commit it and open the pull request yourself, so teammates review a change to team knowledge the same way they review code. Git history is the audit trail, access follows repo permissions, and Mnemolith never commits on its own.

When a pull request changes files that team memories depend on, a GitHub Action comments on it, so outdated knowledge gets caught in review instead of after the merge.

Then: memory for any folder

Early 2027. Memories for folders that aren’t code, tied to PDFs, Word files and spreadsheets and flagged when those change, so a student, a researcher or a small business can keep their AI up to date too. Later, a desktop app that installs like any other app, with no terminal.

Not done yet

The evaluation uses a small sample codebase built for it; real projects are bigger and messier. Recalling and keeping memories up to date costs about 15% more per task than a notes file, and we are working to bring that down. The engine’s log only grows for now.

The local version stays free and open source. Ideas and pushback are welcome on GitHub.
