Where Mnemolith is heading.

Mnemolith gives AI coding tools a shared memory that knows when it’s out of date, and now a whole team can share and review it. Next, it reaches people who don’t write code. Last updated November 10, 2026.

Today

One memory shared by Claude Code, Claude Desktop, Cursor and Codex, tied to the files each fact depends on and flagged when those files change. Mender drafts the fix for a stale memory and you approve it, and a local dashboard shows what your AI knows and why.

It helps: on tasks that need knowledge the code doesn’t show, Claude got 43% right with no memory and 100% with Mnemolith. See the evaluation.

Now: team memory

Version 0.4. Each person keeps their own memories, and each repo can have one shared team memory that every teammate’s AI reads. You share a memory on purpose, after a heads-up that everyone with access to the repo will see it, and a secret check refuses keys and passwords.

Team memories live in the repo as plain files, one per memory. Mnemolith writes the file; you commit it and open the pull request, so teammates review a change to team knowledge the same way they review code. When the code a team memory depends on changes, it’s flagged for everyone. Mnemolith never commits on its own.

Next: more help in review

A first version is in 0.4: mnemolith team action adds a GitHub workflow that comments on a pull request when it changes something team memories depend on, so outdated knowledge gets caught in review instead of after the merge. It’s new and lightly tested. Next for it: keeping mnemolith.md up to date after each merge, and Mender drafting the fix for a flagged team memory.

Then: memory for any folder

Early 2027. Memories for folders that aren’t code, tied to PDFs, Word files and spreadsheets and flagged when those change, so a student, a researcher or a small business can keep their AI up to date too. Later, a desktop app that installs like any other app, with no terminal.

Not done yet

The evaluations use a small sample codebase built for them; real projects are bigger and messier. In that small repo, the outdated flag didn’t change outcomes: Claude noticed code changes on its own. The engine’s log only grows for now.

The local version stays free and open source. Ideas and pushback are welcome on GitHub.
